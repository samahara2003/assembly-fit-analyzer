# Application screenshots

`worked-example.png` is an actual headless Google Chrome capture of the local
Streamlit application, not a mockup. It shows the built-in housing/insert worked
example after Analyze: minimum 5.800, nominal 6.000, maximum 6.500 mm, with
inclusive functional limits 5.800–6.500 mm.

Capture recipe: launch `streamlit_app.py`, open Chrome at a 1440 × 1900 viewport,
select **Use worked example**, confirm **Replace workspace**, select **Analyze**,
wait for the app to finish rendering and capture the viewport. Close popovers
and avoid personal project names or local filesystem paths. The application
theme and layout must remain unchanged; recapture when visible behavior changes.

Captured 20 October 2026 on macOS with Streamlit 1.66.0 and Chrome 155.0.8059.85.
The image shows the editor, assessment, exact metrics and interval chart. The
contribution tables continue below the captured viewport.
